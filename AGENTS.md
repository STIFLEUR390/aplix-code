## Naming — easy to get wrong

- Repo/package: `aplix-code`. Binary and CLI name: **`apc`** (so `[[bin]] name = "apc"`).
- Crate prefix is `apc-`: `apc-core`, `apc-traits`, `apc-agent`, `apc-tools`, `apc-decision`,
  `apc-models`, `apc-memory`, `apc-plugins`, `apc-cli` (the binary crate).
- Config file: `apc.toml`, generated by `apc init`.

## Architecture contract (README §Architecture — keep it when scaffolding)

Cargo workspace, one job per crate, dependency direction outward from the bottom:

```
apc-core      shared types, errors, config — no internal deps
apc-traits    every trait (Model, Tool, Memory, Decision, Plugin) — the plugin contract
apc-agent     agent loop, orchestration only, no I/O
apc-tools     built-in tools: read_file, write_file, list_dir, run_shell
apc-decision  local decision engine (open-jev) + heuristic fallback
apc-models    LLM adapters via the `genai` crate
apc-memory    session + long-term memory backends
apc-plugins   plugin discovery/loading
apc-cli       the `apc` binary
```

Swappable behaviour goes behind a trait in `apc-traits`; never add a provider/backend-specific
dependency to `apc-agent` or `apc-cli`.

## Constraints that come from the product promise (do not silently break)

- **Local-first micro-decisions.** Safety checks and intent/context decisions run on a local
  model (`open-jev`, quantized DeBERTa-v3) in <20 ms, never a cloud call. Heuristic fallback must
  exist so the agent works with no model downloaded.
- **Every shell command passes the Permission Guard** before execution, threshold configurable.
- **No telemetry, analytics or phone-home.**
- **`#![forbid(unsafe_code)]`** in user-facing crates, where possible.
- **Binary < 15 MB**, models downloaded on demand (resumable + SHA-256 verified), never bundled.
- Config precedence, in order: defaults < user < project < local < env < flags.
- Rust 1.80+ minimum; OpenSSL or `rustls` (feature) is the only system dependency expected.

## Commands once the workspace exists

```bash
cargo build --release            # ./target/release/apc --version
cargo test                       # add --workspace as crates land
cargo test -p apc-decision <name>  # single crate / single test
cargo clippy --all-targets -- -D warnings
cargo fmt --check
```

Keep them in sync with the actual `Cargo.toml`; if CI is added, it is the source of truth.

dynamic plugin loading, `apc serve` and the Tauri app are all **post-MVP** — don't scaffold them
for an MVP task.
